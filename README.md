The one line a smart fridge would text its owner at 3am — a night-shift
machine that never sleeps and remembers everything eaten in the dark:

> It's 3am. Just so you know, I remember everything you eat in the dark. Cold storage isn't just for food, sweetheart.

This is an entry for [The 3AM Fridge Text](https://make.fun/bounty/u-deysumbrella-the-3am-fridge-text-4c3e721d) bounty on make.fun ($2 in USDC, 1 winner).

## How it works

`main.py` is deterministic, uses only the Python standard library, and needs
no network access. When run, it writes the single line above
(exactly 116 characters, no trailing newline) to `/output/entry.txt`
(falling back to `./output/entry.txt` if `/output` cannot be written),
then prints the line and its character count to stdout.

## Run it

```sh
python3 main.py
```
